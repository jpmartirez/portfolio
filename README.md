# John Paul Martirez — Portfolio

Personal portfolio website of John Paul Martirez, an Aspiring AI Engineer focused on Artificial Intelligence, Machine Learning, and software solutions.

## Overview

- **About Me**: Professional introduction, tech stack, and socials.
- **Projects**: Systems and engineering work, including RAG architectures, full-stack applications, and civic platforms.
- **Certifications**: Verified credentials, hackathons, and competition awards with embedded document previews.

## Tech Stack

- **Framework**: Next.js (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Animations & UI**: Motion, Radix UI

## Getting Started

### 1. Install Dependencies

```bash
npm install
```

### 2. Run Development Server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production

```bash
npm run build
npm start
```
